## Current project

### [PitGuard](https://github.com/adityakumar0308/pitguard)

Point-in-time reconstruction and revision lineage for pandas datasets.

PitGuard separates effective, publication, ingestion, revision, prediction, and label times so
historical analysis does not silently use future information. It includes traceable as-of joins,
bitemporal snapshots, leakage audits, contamination comparisons, and purged walk-forward splits.
